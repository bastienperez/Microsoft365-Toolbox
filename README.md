# Microsoft365-Toolbox

> **These scripts are moving to [PS365](https://github.com/bastienperez/PS365).**
>
> PS365 is a PowerShell module for Microsoft 365 administration: Exchange Online,
> Entra ID, Intune and related services, through automation friendly cmdlets.
>
> The scripts in this repository are being migrated there one at a time. Once a
> script has moved, it is removed from here and the module version is the one to use.
>
> Moved so far:
>
> - `Exchange/Get-MailAutoForwarded.ps1` is now `Get-ExMailAutoForwarded` in PS365.
> - `Exchange/Get-MailboxForwarding.ps1` is now `Get-ExMailboxForwarding` in PS365.

Some useful scripts to get infos about Microsoft 365 tenant.
